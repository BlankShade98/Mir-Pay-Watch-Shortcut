Небольшое легковесное приложение-шорткат для Mir Pay Watch. Сделано с помощью Google Antigravity (Gemini 4 Hydrogen).
Использует шорткат голосового ассистента по умолчанию, сделано в первую очередь для смарт-часов Google Pixel Watch, так как жест вызова приложения для бесконтактной оплаты по умолчанию (двойное нажатие на коронку) на этих смарт-часах изменить невозможно без Root-прав.
Приложение не имеет внутренних настроек, UI и иконки в лаунчере.
